## Fitness Tracker iOS

App iOS nativa per il tracking degli allenamenti in palestra.

- **Lingua:** Italiana
- **Tecnologie:** Swift, SwiftUI, SwiftData, ActivityKit, WidgetKit
- **Distribuzione:** TestFlight → App Store
- **Filosofia:** local-first, minimal, veloce durante l'allenamento

### Documentazione
